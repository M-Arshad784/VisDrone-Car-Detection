# VisDrone Car Detection 🚗🚁

## 📌 Overview

This project uses **Computer Vision and YOLO** to detect cars in aerial images captured by drones. It focuses on vehicle detection from a bird's-eye view using the VisDrone dataset.

## ✨ Features

- Car detection in drone images
- YOLO-based object detection
- Bounding boxes around detected cars
- Confidence scores for predictions
- Aerial image analysis

## 🛠️ Technologies Used

- Python
- YOLO
- Ultralytics
- OpenCV
- Computer Vision
- VisDrone Dataset

## 🎯 Applications

- Aerial traffic monitoring
- Vehicle counting
- Traffic congestion analysis
- Smart city surveillance
- Drone-based road monitoring

## 🚀 Future Improvements

- Real-time car detection from drone video
- Vehicle tracking
- Traffic density estimation
- Automatic vehicle counting
- Integration with live drone cameras
